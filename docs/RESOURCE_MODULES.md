# 全局完整模块接入

本轮目标：让完整专家模块、普通 Skill 和 MCP 服务共同经过已有 GraphToolCall 检索；不拆改专家角色和原始流程，不把第三方库全文注入上下文。

最新检索改动已在本机全局生效：英文BM25固定词项贡献预计算、明确且唯一的MCP服务身份约束。116条带目标诊断请求前4名命中65→71，无已测退化；100个不同请求同时发起均成功。中文和长尾未证明全面提速，完整范围、负结果及复现方式见[检索运行时实测](RETRIEVAL_RUNTIME_UPGRADE.md)。下文首次接入的PID与报告是该次历史时点，当前状态以新实测报告为准。

## 已安装内容与边界

新增全局目录为 `~/.codex/resource-packages/`、`~/.codex/resource-adapters/`；入口目录为 `~/.codex/skill-registry/resource-modules.json`。它们不依赖当前工作区。包含 447 个专家、3,307 个 Skill 内容版本（2,883 个名称）、478 个 MCP 服务描述符，共 4,232 个入口。这些类别相互包含，不能加总解释为独立能力数量。

专家仍是一个完整图节点。成员角色、内部 Skill、脚本和资料留在原目录。2026-10-25 起，本机包外入口直接包含原始主角色全文，模型选中后一次全文读取即可按原流程工作；不再映射宿主工具，不再要求第二次读取主角色。缺少原生工具或主角色不唯一时明确受阻，不用“预算耗尽即通过”等原始条款替代实际验收。部署和验证边界见[专家统一入口](EXPERT_DIRECT_ENTRY.md)。

复制了 48,454 个文件、1,947,339,932 字节。原字节核验无差异，但有 45 项明确排除，包含敏感/机器状态文件、外部及损坏符号链接，因此不是“无损复制全部文件”。依赖专家父目录数据的 Skill 经入口哈希匹配后指向完整专家包内原路径。

原资源的许可和来源保留；本轮未把完整第三方镜像提交进主仓库，也未把来源不明的认证配置当作可安装 MCP。全局可见不等于已认证、免费、有效或适合所有任务。

## MCP 按需执行

服务节点指向全局描述符，不代表 Codex 已静态注册 478 个工具服务器。命中后先发现当前 schema，再用原工具名和参数调用；需要认证或宿主进程的服务保持依赖未满足状态，不自动启动任意下载命令。

全局执行器位于 `~/.codex/tools/resource-modules/resource-mcp-cli.mjs`，支持 `describe`、`list-tools` 和 `call`，通过精确 module ID 查注册表，不接受任意地址，不读取源凭据。默认仅允许已确认的匿名只读业务；未知成本和副作用默认拒绝。覆盖标志只能表达当前任务已经具备的真实授权，不能创造权限。普通用户不需要手动使用这些命令；由命中模块的 Agent 按任务范围使用。

## 可复现维护工具

- `scripts/import-resource-modules.mjs --source <资源库> --output <全局Codex目录> --install`：完整包安装和外部适配；并发可配，当前实装为 20 路。
- `scripts/verify-resource-packages.mjs`：独立原包与安装入口哈希核验。
- `scripts/stage-resource-graph.py`：隔离构建全量双语候选图，不替换生产。
- `scripts/verify-resource-retrieval.py`、`scripts/verify-resource-hook.py`：检索与真实 Hook 检查，保留失败。
- `scripts/publish-resource-graph.mjs --check`：验证被测字节、输入、模块覆盖和向量哈希，不写生产；实际发布先写向量和运行时，最后原子替换图，出错从内存恢复，不创建持久备份。

这些是维护/复现实验入口，不是要求用户逐个安装资源。新增资源仍先安装完整包，再构建和验证候选；不在每次请求中扫描或重新编码整个库。

## 路由验收状态

全量候选图有 19,753 个节点，其中 4,232 个新完整模块的 ID 全覆盖；另含原有 15,494 个 Skill 和 27 个原生 MCP 工具。发布器的只读校验已通过输入、图、向量及运行时哈希检查，但该检查不是召回或执行验收。

两组分别 28 条冻结中英查询中，候选池语义保护前后的指定身份 top4 命中为 14→15、10→11。精确名称不等于功能覆盖：独立审阅首轮原始 top4，22 条覆盖主动作、5 条部分覆盖、1 条没有覆盖；这只是单模型相关性审阅，不是业务准确率。约束版本仍存在真实退化：中文学术翻译与英文社保连接器的覆盖减弱；PDF 子 Skill 名掉出，但完整父专家仍在，不算能力丢失。

首个已复现偏差包括：语义排名靠前的节点被 500 项候选池删除、英文与中文通道描述覆盖不同，以及融合和 MMR 多样性重排把完整模块挤出最终 4 项。候选池修复和 7 项回归通过，不意味着其他边界已经修好。关闭 MMR 或把双语通道直接融合也有增有退，未据此盲目替换生产。

真实候选常驻 worker 在两个隔离工作区的 6 次 Hook 中全部返回合法上下文，但仅 3 次含指定目标；仅中文三条命中。原始结果、反例、消融和逐函数诊断保留在 `.reports/resource-*.json`；可读解释见 [相关性审阅](RESOURCE_RETRIEVAL_REVIEW.md)。生产启用状态须单独记录，不能将全局安装、候选构建、协议成功或上下文返回表述为生产路由已完成。

本轮重新执行的定向检查：安装器 7 项、发布器 10 项、资源图 6 项、语义候选保护 7 项通过；MCP 传输及 CLI 门禁测试通过。未运行不可用的全仓 PowerShell 门禁，不宣称全仓发布检查通过。
