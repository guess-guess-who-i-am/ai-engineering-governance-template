# 文档事实归属

最新用户要求决定目标；`CONTEXT.md` 决定本项目术语与边界；`DESIGN.md` 决定视觉语言；拥有该行为的契约、代码和可复现实验决定实际能力。计划和文件存在不是运行成功。

项目局部规则以最近的 `AGENTS.md` 为准。专项步骤读取匹配 Skill，不扫描整个方法论档案。文件缺失时检查真实所有者，不虚构路径或假称已读取。

同一事实只维护一个正文源，其他文档引用它：中文方法论源由发布器生成英文和审阅镜像；Windows 安装基线与明确批准的策略改动由安装清单分别记录。历史快照不作为当前指令。

本项目的真实检查入口是 `scripts/check.ps1`，窄范围修改先运行所属脚本或测试。部署验证见 `docs/MAC_PROFILE_WINDOWS_DEPLOYMENT.md`；当前任务状态见 `task-tree.md`，详细日志放 `.reports/`。
