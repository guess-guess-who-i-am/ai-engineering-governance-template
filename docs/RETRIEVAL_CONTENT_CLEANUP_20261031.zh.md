# 全局推荐索引字段清理

2026-10-31 已发布到本机和 194 服务器的全局图及常驻 worker。原始专家包、Skill 原文及调用参数没有修改；本轮代码与报告已纳入 Git 交付。

## 检索内容

| 资源 | 参与相关性计算的文本 | 排除字段 |
| --- | --- | --- |
| 专家 | 可读名称；description、displayDescription、profession 中的能力说明；无上述说明时使用原角色能力范围 | 内部 ID、tags、defaultInitPrompt、quickPrompts |
| 外部 Skill | 可读名称、description、problem_cn、when_cn | 内部 ID、c1、c2、key、traits_cn、diff_cn |
| 自有与完整模块 Skill | 可读名称、声明的能力描述及已有描述译文 | 内部工具 ID、标签、分类字段 |
| 原生 MCP | 公共函数名、能力描述及已有译文 | 传输前缀、内部工具 ID、参数名 |

同一白名单同时用于中英文工具向量、BM25、关键词入口与名称加权；描述重排向量仅编码清理后的描述。关闭把内部节点 ID 反向分词的结构分类倒排，显式依赖遍历和 2/4/2 类别配额保留。向量继续完整分窗编码，不恢复截断。

内部键仍存在于资源定位、调用、显式依赖和同分时的确定性排序中，不作为语义文本。生产 MMR 使用清理后的密集向量；本轮不宣称上游独立无向量 MMR 已修改。历史隔离实验脚本不是生产构建入口。
