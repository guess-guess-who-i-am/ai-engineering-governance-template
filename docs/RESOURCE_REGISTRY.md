# 资源登记

这里登记会持续存在、产生费用、承载数据、占用稀缺容量或影响其他任务的资源。一次性临时文件和进程只有在可能冲突、泄漏或遗留时才需要登记。

## 必须登记的资源

- 数据库、对象存储、向量索引、共享数据集和制品库。
- 长期服务、端口、容器、队列、定时任务和外部 Webhook。
- GPU、模型端点、付费 API、账号额度、许可证和共享测试环境。
- 不能仅靠 Git 重建的模型、数据、媒体、大文件或实验产物。
- 需要权限、清理、备份、恢复、监控或成本责任的临时资源。

密钥值不登记。只记录秘密管理器中的引用名、所需权限和轮换责任。

## 资源门禁

- `Temporary` 必须有负责人、失效条件和清理动作。
- `Active` 必须有真实消费者、访问边界和适用的健康、恢复、容量或费用信息。
- 发布前检查是否存在登记外的常驻进程、端口、云资源、账号额度或唯一数据副本。
- 资源退役时先验证消费者已迁移或停止，再执行清理并记录完成时间。
- 大文件使用逻辑 ID、不可变版本和摘要；代码不得硬编码个人盘符、临时 URL 或本机绝对路径。
