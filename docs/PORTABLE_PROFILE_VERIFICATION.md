# 三平台安装交付验收

日期：2026-10-18。实现目标：三平台同源提示词、全局Skills、常驻图检索和点击安装；安装不调用模型API、不创建Agent、不复制认证。

## 构建边界

- 主入口为根目录三个平台启动文件，共用 scripts/deploy-global-profile.mjs；保留旧Mac入口兼容文件名。
- codex-profile 继续作为唯一内容源，不再为Windows维护另一套旧提示词。现有mac目录里的共享处理器在三平台复用，名字不等于只在Mac执行。
- 系统适配仅负责Python布局、Hook命令引用、本地进程间通信和服务管理；不把Mac虚拟环境打包到Linux/Windows。
- 新用户全量部署采用严格库校验；旧Linux窄迁移入口保留，默认不覆盖用户提示词。
- 先闭环共享文件安装，再测真实进程池、embedding与系统启动；未测表面不以静态配置代替验收。

## 自启动约定

Linux为systemd用户服务+linger，可在登录前启动。Mac为LaunchAgent、Windows为当前用户登录触发的计划任务，两者必须用户登录；不承诺登录前运行。本轮不重启真实整机。

服务安装不显式停止已有worker；后续更新替换脚本时，旧worker可能按已有热更新机制自行退出，再由服务管理器拉起。不能声称升级绝对没有任何重连窗口。

## 依赖与凭据

Skill库按portable-dependencies.json固定提交和目录checksum恢复；task-tree的新克隆也固定到提交。embedding模型首次从模型源下载，当前未增加模型revision锁，因此不能宣称完全可重复的离线供应链。系统Node、Python和Git通过用户正常图形安装，运行前检测；Linux另预装CPU-only PyTorch避免误拉CUDA依赖。

敏感扫描、治理验证与完整发布门禁分别报告。当前本机没有pwsh，PowerShell门禁交由原生CI；不把Node语法检查冒充PowerShell验证。官方OpenAI文档与StackOverflow在本机仍返回403，安装行为依据仓库源、真实运行端及可重复测试。
