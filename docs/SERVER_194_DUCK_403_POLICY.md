# 194：duck 的 HTTP 403 不再触发 KPOCE 回退

验收时间：2026-10-22。仅修改 192.168.4.194 的 hyf 用户路由器；不发布 Git，不改其他服务器。

## 当前行为

- 私有请求在 duck 收到 HTTP 403 时，保留原始响应状态和正文，立即返回客户端；不调用 KPOCE，不自动重复同凭据的 403 请求。
- 403 规则位于供应商错误识别之前，因此正文包含“可重试的供应商错误”也不能覆盖这条策略。
- 普通网络超时仍先重试 duck 一次，耗尽后保留原有备用策略；503、524 等其他回退不变。
- 后续新请求仍从 duck 开始。没有改变主路由、模型、代理、密钥或其他供应商的策略。
- 这项修改阻止供应商切换，不解决上游为什么返回 403，也不承诺上游长期可用。

HTTP 语义依据：[RFC 9110 §15.5.4](https://www.rfc-editor.org/rfc/rfc9110.html#section-15.5.4)。403 不宜使用同样凭据自动重复；本轮没有增加盲目重试。
