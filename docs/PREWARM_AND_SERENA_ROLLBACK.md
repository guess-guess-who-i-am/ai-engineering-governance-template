# 双语预热、离线向量与 Serena 撤回

2026-10-20，用户要求提前完成多语模型初始化和 embedding，并撤回更慢、更耗 token 的 Serena 默认导航。本轮只部署本机全局与右键安装源，未推送 Git，未重新验收远程服务器或其他操作系统。

## 当前方案

- 一张全局图包含 22 个自有 Skill、15,471 个有效外部 Skill 和 24 个 MCP 工具。Serena 默认 MCP 配置块、导航 Skill、aliases 及专属运行文件直接删除，不保留失败接入的备份；本配置的 Serena 后台已停止。恢复 `rg` 和按需局部读取，不删除用户自有 Serena 数据或其他 MCP。
- 检索描述的 embedding 在建图时生成；另外发现上游重排还会对候选的纯描述重新编码，因此增加两份中英文纯描述向量缓存，离线生成并持久保存。它们与检索用的“名称+描述”向量分开，不能直接混用。
- 两份重排向量合计约 48.4 MiB 磁盘，使用相对文件名、内容哈希、文本身份和形状验证；驻留内存时每个进程都有自己的缓存，这个文件大小不代表整套服务的 RAM。
- 查询进程启动时加载模型、索引、检索和重排向量，并各跑一次中英文真实检索；进程池所有初始化完成后才能处理普通请求。图更新会失效旧缓存并重新预热两种语言；崩溃恢复亦执行初始化。不会每条请求重新加载全图。
- 未知的新问题仍要计算查询向量，无法提前计算无限的未来输入；重复输入复用有界缓存。离线计算只是把静态工作移到启动/更新阶段，没有消除这部分耗时，也没有证明总任务成本下降。
- 一键安装和 Finder 右键安装源已同步；升级时执行无备份的定向删除迁移，避免重新启用 Serena。其他 provider、认证和非受管 MCP 保持原样；其他功能原有的备份策略不变，实验报告保留。

## 实测

`.reports/retrieval-prewarm-retirement.json`：四个真实查询进程、16 条不同中英文请求全部成功，两个语言均已就绪；各进程加载计数稳定为 1，均有全库静态描述向量。两个工作目录实际 Hook 均正确推荐调试 Skill，不含 Serena；约 240ms 和 233ms。查询和 Hook 延迟不是受控前后对比，不据此宣称整体提速百分比或 token 降幅。

本轮还运行全量 100 条不同长查询负载，100/100 成功，全批 17.811 秒，单请求 p95 16.734 秒，使用四个真实查询进程；结果见 `.reports/prewarmed-descriptions-load100.json`。期间另外执行了三条 Hook 验证，也全部正确，但因排队耗时约 16.7–17.0 秒；见 `.reports/global-chinese-routing-without-serena.json`。这说明预热消除了初始化的在线开销，并没有消除满载排队。该批次并非绝对隔离的性能对照，历史 21.6 秒批次对应之前的图/源码，不能据此声称严格测得提速比例。

再次调用实际全局刷新器，图内容哈希、inode 和 mtime 均保持不变，证明相同输入不会重新计算全库 embedding；证据为 `.reports/prewarm-refresh-idempotence.json`。

窄验证通过：worker 16 项（包括预计算描述不再编码、不会被查询 LRU 驱逐、崩溃恢复和换图）、中文/向量缓存校验 8 项、预热 EOF 恢复及拒绝仅英文就绪、真实 loopback/auth 与两进程调用、Mac 一键与右键重复部署、便携安装模拟。后续按用户要求将 Serena 撤回改为无备份删除；单独验证配置及嵌套表删除、专属文件清理、幂等、只读检查及用户数据/报告隔离。缺少 pwsh，未运行 PowerShell 全库门禁；模拟不代表其他系统实机验收。

维护入口：`scripts/warm-global-graph.py`、`scripts/precompute-description-embeddings.py`、`scripts/retire-serena-mcp.mjs`、`scripts/test-prewarmed-global-routing.py`。常规新增/更新 Skill 或 MCP 通过原全局刷新器重建所需向量，不需手动逐篇配置。

Serena 的真实任务负结果保留于 [此前实验](CHINESE_RETRIEVAL_SERENA_EVIDENCE.md)。本次未再跑 LLM 任务准确率及总 token 对照，不把检索成功或短工具输出当作这些指标的改善。

后续无备份定向删除的范围、报告哈希验收、本机部署检查的未完成项及任务树旧值→新值回执，见 [Serena 定向清理验收](SERENA_REMOVAL.md)。
