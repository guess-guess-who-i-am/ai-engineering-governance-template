# 全局 Skill 产物交接关系

本轮目标是让全局推荐能说明“选中这个 Skill 后，哪些 Skill 可能消费它的产物”，并验证实际 Hook 会显示这些关系。所有工作区仍共用用户级常驻 GraphToolCall；项目中不安装另一套 Skill。

## 关系如何建立和使用

- 离线构图读取入口中明确的输入、输出章节或标签，保留具名产物、声明行号及原文件 SHA-256。精确匹配相同相对路径；不同生产者存在歧义时不连边。示例、否定、代码块、普通叙述、泛用文件名和目录穿越均排除。此策略保守，会漏掉自然语言描述或不同名字的同类产物。
- 采用 GraphToolCall 0.46.0 原生 `PRECEDES`，方向为生产者→消费者，置信标记为 `INFERRED`。这是可能的交接，不是必须依赖，不证明格式兼容，也不授权自动执行。现有 `REQUIRES` 不被覆盖。
- MCP 保留 `outputSchema`；存在声明时，仅连接同服务、同具体标识字段、同类型的输入输出。当前 Mac 的27个 MCP 工具均没有输出 Schema，因此本轮没有凭空增加 MCP 交接边；此路径以真实库的合成 Schema 用例验证。
- 常驻 Worker 返回主候选及一跳 `artifact_links`；查询时不再读取全库正文，不新增模型请求。交接提示总数不超过该次候选数；Hook 标明上下游方向、产物及关联入口，只有选用当前候选时才考虑。
- 显式点名和图检索得到同一入口时，去重保留原排名及图关系提示。提示不修改主候选分数或强行插入关联 Skill。

## 实测与边界

Mac 全量图：19,756个工具节点，包括15,497个 Skill、27个 MCP 工具及4,232个资源模块。19,712份唯一入口可读，384条生产声明、150条消费声明建立9条交接边，读取错误为0。英文、中文向量全部按完全相同文本复用，没有重新编码。

| 固定对照 | 原图 | 加关系及交接提示 |
|---|---:|---:|
| 6例指定生产者的后续 Skill 进入主推荐前8 | 2/6 | 2/6 |
| 主推荐或生产者的交接提示覆盖目标 | 2/6 | 6/6 |
| 既有中英文留出查询命中 | 21/28 | 21/28 |

仅增加图边没有提高主推荐命中：当前预过滤与尾部图候选注入会限制邻居进入前8。交接提示补足了这6例的后续发现，但查询直接包含生产者名称，且只跑一遍；不能据此声称普遍检索准确率、任务成功率或速度改善。留出集仍有7例未命中，本轮没有掩盖该缺口。

9条边另经打乱顺序的 LLM 语义盲评，均被接受为“可能交接”；一条明确正确和一条双方均输入的错误校准均判断正确。模型要求引用双方原文，并逐条披露条件输入、其他必需材料及格式未验证等边界。该审查不是实际跨 Skill 执行证据。

Mac 与194均已按各自路径发布全局图，受影响文件已备份。两机各做6路真实 Hook 调用，均6/6成功，开始/结束区间证明调用重叠；单轮预热后观测分别为0.38–0.49秒、0.39–0.84秒，不能视为冷启动或长期速度保证。194保留本机23个 MCP 工具；Mac 的27个包含桌面环境差异。发布图和运行源码校验值、固定样例与并发区间见[精简实测记录](evidence/artifact-relations-20261105.json)。

当前边包括：交易概念→策略设计、表格 Schema→附录表格、模块计划→幻灯片骨架、金融分析→入门解释、控制清单→测试计划、设计文档→配乐，以及论文大纲→表格 Schema／引文分配／主张证据矩阵。

## 重建、迁移和验证

安装器自动复制 `artifact_relations.py`，正常全局构图自动建立关系；增加或修改 Skill 正文、输入输出声明、MCP Schema 后须重建并发布全局图。不会每轮扫描第三方库检测正文变化。

在其他机器安装同一版本并恢复其全局资源后，使用目标机器的实际路径构图。已有图可由 `scripts/build-global-graph-cached.py --hooks <候选Hook目录>` 复用经过校验的原文本向量，输出独立候选目录；发布器先校验全部声明源和向量，再写入全局目录，图文件最后提交。`--check` 无写入，发布失败自动回滚。生产验证前额外备份受影响文件，便于事后恢复。

可复现实验入口：

```sh
"$HOME/.codex/tools/graph-tool-call-venv/bin/python" scripts/test-artifact-relations.py
"$HOME/.codex/tools/graph-tool-call-venv/bin/python" scripts/evaluate-artifact-relations.py \
  --baseline /path/to/original/skills.graph.json \
  --candidate /path/to/candidate/skills.graph.json --output /tmp/relation-evaluation.json
```

测试需要 Node.js；未在 PATH 时，设置 `CODEX_TEST_NODE` 为实际 Node 可执行文件。关系测试包含真实 Unix socket Worker→Hook 输出、双向提示、现有依赖不覆盖、负例排除、MCP 类型边界与图保存读取。相邻 Worker 测试还覆盖100请求突发／错峰、进程故障恢复和超时取消。`scripts/check.ps1` 的15项门禁、安装器更新／检查／失败回滚也已通过。

上游依据：[GraphToolCall](https://github.com/SonAIengine/graph-tool-call) 的原生关系、输入输出契约与图遍历实现。本轮没有启用全量名称／CRUD 猜测依赖，也没有把文件路径一致解释成 Schema 已兼容。
