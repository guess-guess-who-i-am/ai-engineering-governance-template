# 全局 Skill 检索共享内存修复（2026-11-17）

本轮目标是在保留完整图、双语embedding和全局路由的条件下，减少重复常驻资源。已部署一个 Python 进程、默认两个计算线程；没有删减工具、截断查询、更换模型或降低结果数量。实测内存足迹减少约41%～48%，高负载延迟仍未达到“100个请求都很快”的目标。

后续同图对比已确认并发性能退化：100个相同短输入的P95由旧两进程11.86秒变为共享两线程16.63秒。不能仅凭内存下降及请求成功认定整体优化完成；原因与不同测量口径见[延迟回归核查](GRAPH_LATENCY_REGRESSION_20261117.zh.md)。

## 根因与修复

1. 原协调进程启动两个计算进程，各自装载完整图、模型和缓存。现在每个图版本只建一个共享实例，以有界线程处理查询；128个在途连接与256个等待连接保持不变。模型编码沿用互斥保护，相同请求继续合并，单个调用者超时不会取消其他等待者的查询。
2. 初始化失败后，后续请求可能反复加载全图。现在同一版本的请求等待同一个初始化结果，失败传播原始错误，不重复初始化。真实部署还发现中文官方模型缓存缺失；安装器先准备清单声明的模型，服务运行阶段保持离线。
3. Hook先取得服务锁时，supervisor可能每三秒启动一次必败的Python及预热进程。新增轻量状态请求，supervisor直接接管已存在的服务，仅服务消失后启动替代者。
4. 每次候选检索都重新扫描工具类别。现在按不可变图缓存类别位置，并复制待排序位置，避免跨请求修改共享缓存。预热与旧版本关闭后执行垃圾收集及macOS分配器空闲页释放；不丢弃图或模型。

图更新仍先准备新版本，成功才原子切换，旧请求继续使用旧版本。无停顿更新需要短暂保存新旧两份数据，因此稳态节省不等于峰值上限。

## 实测证据与边界

测量机器为16GB macOS，其他应用及外部检索客户端未关闭。内存使用系统`footprint`的`phys_footprint`，以下为十进制GB，不能与RSS混比。

| 场景 | 结果 |
|---|---|
| 原两个计算进程 | 1,784,236,816 + 1,847,724,864字节，合计3.632GB；未计小型协调进程 |
| 共享进程预热后 | 1,875,331,928字节，约1.875GB，减少48.4% |
| 共享进程百路压测后 | 2,149,486,240字节，约2.149GB，减少40.8% |
| 新进程记录的历史峰值 | 4,846,376,504字节；仅证明启动、更新或压力期间曾达此值，未单独隔离峰值来源 |
| 无本轮测试运行的5秒窗口 | 使用1.01 CPU秒，约单核20.2%；外部客户端仍可请求，不能视为严格空闲CPU |
| 固定同一图13组查询 | 英文、中文及长输入的完整返回记录与旧实现完全相同 |
| 最新100个不同长输入突发 | 100/100成功，P95 32.5183秒，最大34.0176秒 |
| 最新100个不同长输入错峰 | 100/100成功，P95 41.0637秒，最大43.2443秒 |

原突发样本P95为53.0544秒，但图和主机负载并非严格相同，不能据此宣称确定的延迟提升比例。探索阶段出现过90/100、94/100及隔离服务20/100成功的压力测试；测试争用和主机内存压力未完全隔离。保留这些失败，不能用最新成功样本保证任意100路都不超时。低延迟高负载与严格空闲CPU仍是未闭合边界。

固定结果对比使用含19,756个工具的不可变图，SHA-256为`d419138e8f95c6f8e2710ac57576e95b91c6babb611b13e8cb9994e584ca036f`。这证明此次线程化未改变这些查询结果，不证明推荐质量已全面提高。

## 设计依据

- [Python concurrent.futures](https://docs.python.org/3/library/concurrent.futures.html)：有界线程执行、Future错误和关闭语义。
- [Hugging Face Text Embeddings Inference](https://github.com/huggingface/text-embeddings-inference)：共享模型服务与批处理的成熟参考，本轮没有引入该服务或声称实现其吞吐性能。
- Apple官方SDK的`malloc/malloc.h`声明：`malloc_zone_pressure_relief(NULL, 0)`请求所有分配区尽力释放空闲页，返回实际释放字节；无法保证释放全部空闲内存。本机MacOSX15.4 SDK已核对。

Stack Overflow本轮未检索到可直接支持该实现的权威答案，未作为修复依据。
