# GitHub Delivery Method

## Routing instruction

Apply the rule below when this Skill is selected. This is the user's original rule translated into English, not a rewritten summary. External GitHub writes still require authorization in the active request or established project workflow.

## User's original wording — English translation

- After every completed modification, such as code changes, update it on GitHub, regardless of size, except for datasets. Separate GitHub repositories according to the current projects. If no repository exists, create one, and then set the repository for the current project to private.
