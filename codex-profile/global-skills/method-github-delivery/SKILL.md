# GitHub Delivery Method

## Routing instruction

Apply the rule below when this Skill is selected. This is the user's original rule translated into English, not a rewritten summary. Follow the user's current request and standing delivery rule; do not ask again for confirmation of an already requested commit or push.

## User's original wording — English translation

- After every completed change, such as code changes, update it on GitHub; update changes large and small, except datasets. Organize GitHub repositories by the current project; if there is no repository, create one, then set the current project's repository to private.
