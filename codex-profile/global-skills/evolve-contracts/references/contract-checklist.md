# Contract evidence matrix

| Concern | Evidence |
|---|---|
| Authority | One canonical contract or schema contains the new behavior |
| Producer | Emits the exact documented success and failure semantics |
| Consumer | Parses and presents the new behavior without hidden fallback |
| Errors | Stable machine-readable branch and safe human message |
| Security | Authentication, authorization, secret and tenant boundaries preserved |
| Edge behavior | Missing, invalid, repeated, empty, and boundary values tested as applicable |
| End to end | A real consumer reaches the producer and verifies business behavior |
| Cleanup | Search finds no obsolete names, paths, fields, examples, or adapters |
